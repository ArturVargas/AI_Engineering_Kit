# Design brief

## Propósito

Definir la experiencia que necesita el usuario y, cuando haga falta, la dirección visual antes de implementar una pantalla, flujo, landing o rediseño material.

## Cuándo usarlo

Úsalo para una nueva interfaz visible, un flujo relevante, una landing de producción o un rediseño material. No lo uses para backend, APIs, infraestructura ni ajustes visuales mínimos que puedan verificarse directamente.
