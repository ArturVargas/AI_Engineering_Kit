# Reference pack

## Propósito

Registrar referencias visuales o de UX de manera que enseñen principios reutilizables sin convertirse en instrucciones de copia.

## Cuándo usarlo

Úsalo cuando una referencia externa aporte claridad relevante para una pantalla, landing, rediseño o dirección visual. No es obligatorio para cambios pequeños ni para proyectos con un sistema de diseño que ya resuelve la decisión.
