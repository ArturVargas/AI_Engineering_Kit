# Estándar de observabilidad

- Registrar errores con contexto suficiente para investigarlos, sin secretos ni datos sensibles innecesarios.
- Medir la tarea crítica del usuario, la disponibilidad y los fallos de integraciones.
- Definir alertas accionables, propietario y runbook antes de depender de ellas.
- Cada incidente relevante deja una decisión o acción preventiva rastreable.
